# SAVE THE WORKER

A colorful, cartoon-style construction safety puzzle game built with HTML, CSS, JavaScript, and Canvas.

## Live game

After GitHub Pages publishes the repository, open:

`https://abhilaosales-wq.github.io/SAVE-THE-WORKER/`

## Files

- `index.html` — the complete standalone game.
- `README.md` — this project guide.

## Features

- Draw a route from the construction worker to the safe exit.
- Hazards include fire, electricity, saws, holes, barriers, and water.
- 50 level progression with coins, XP, lives, and simple sound effects.
- Mouse and touch controls.
- Progress saved locally in the browser using `localStorage`.
- No build tools or external libraries required.

## Run locally

1. Download `index.html`.
2. Double-click it to open it in a modern browser.

## Publish on GitHub Pages

1. Open the repository `abhilaosales-wq/SAVE-THE-WORKER`.
2. In the **Code** tab, upload both `index.html` and `README.md` directly into the repository root.
3. Open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to finish deploying, then open the live game link above. Refresh with `Ctrl + F5` if an older version is cached.
